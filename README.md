# Gerenciador de Tarefas com Recoil

Este projeto é um Gerenciador de Tarefas (Todo List) desenvolvido como parte do curso da EBAC. O objetivo principal foi aplicar conceitos avançados de gerenciamento de estado global com **Recoil** e configurar um pipeline de **CI/CD**.

## 🚀 Tecnologias Utilizadas

- **React** (com Vite)
- **TypeScript**
- **Recoil** (Gerenciamento de estado)
- **Tailwind CSS** (Estilização)
- **GitHub Actions** (CI/CD)

## 🧠 Arquitetura Recoil

O projeto utiliza uma estrutura organizada para facilitar a manutenção:
- **Atoms:** Estado global das tarefas e filtros.
- **Selectors:** Lógica para filtrar tarefas (Pendentes, Concluídas, Todas) e cálculos de progresso.
